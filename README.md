# Business Card

A simple, responsive personal business card built with HTML and CSS.

## Features
- Clean, modern design
- Circular profile photo
- Hover effect on the photo
- Responsive layout

## Tech Stack
- HTML
- CSS

## Live Demo
[View it here](https://idriss-business-card.netlify.app)

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
